# Shock 風格改版計畫

參考：Terkoiz《Shock》1～3 這類火柴人格鬥動畫。目標是保留 MVP 的街機闖關架構，把**戰鬥手感、動作流暢度與打擊演出**往這類動畫靠攏。用詞見 [GLOSSARY.md](../GLOSSARY.md)。

## 已定案的決定

| # | 主題 | 決定 |
|---|---|---|
| 1 | 範圍 | 打擊演出＋戰鬥系統＋動作流暢度；美術只動比例與背景 |
| 2 | 人物比例 | 3.5 頭身 → 約 5.5 頭身 |
| 3 | 背景 | 扁平插畫風：大色塊、柔和漸層、淡色低對比；保留樓層主題色調，讓角色突出 |
| 4 | 遊戲架構 | 保留樓層／區段／Boss／武器／排行榜 |
| 5 | 尺寸 | 頭直徑 12 → 約 9px，身高約 48px，四肢加長 |
| 6 | 浮空 | ↑+Z 挑空技；空中命中即追擊；浮空上限約 5 下；跳躍中 Z→Z→X 空中連段，X 砸地反彈 |
| 7 | 牆 | 敵人撞牆反彈（額外傷害、可追打）；特務蹬牆跳 |
| 8 | 翻滾 | ↓+空白 前滾翻，短暫無敵，可穿過敵人 |
| 9 | 演出 | 殘影、衝擊閃光、重擊鏡頭推近；慢動作只用在每波最後一擊、Boss 掉命條、打倒 Boss |
| 10 | 節奏 | 特務移動 +40%、跳更高滯空更久、起手 -20%；敵人移動加快但起手預告不變 |
| 11 | 敵人靈活度 | 雜兵維持地面打法；Ryu 加空翻斬 |
| 12 | Boss 與浮空 | Boss 不會被打上空中（已有韌性機制） |
| 13 | 武器與浮空 | 拿武器時不能挑空（招式停用）；但武器打中空中的敵人算追擊 |
| 14 | 特務被浮空 | 不會；特務照舊倒地、起身無敵 |

## 里程碑

1. ✅ **比例與節奏**：5.5 頭身骨架、重調所有姿勢與判定；特務、敵人速度與跳躍參數
2. ✅ **浮空系統**：挑空技、追擊、浮空上限、空中連段與砸地反彈、武器追擊、Boss 不浮空
3. ✅ **牆與翻滾**：撞牆反彈、蹬牆跳、翻滾無敵
4. **打擊演出**：殘影、衝擊閃光、鏡頭推近、關鍵時刻慢動作
5. **收尾**：（背景已提前改為扁平插畫風）Ryu 空翻斬、整體數值調整

每個里程碑完成後提交，並請使用者實際試玩回饋手感。
