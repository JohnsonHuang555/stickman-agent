# 遊戲設計文件 (MVP)

用詞以 [GLOSSARY.md](../GLOSSARY.md) 為準。v2 項目見 [v2-backlog.md](./v2-backlog.md)。

## 技術

- Vite + TypeScript + Canvas 2D，無遊戲框架
- 邏輯座標 480×270；畫布依視窗與螢幕解析度（devicePixelRatio）高解析度繪製，線條與文字清晰
- 火柴人：程式化骨架 + 關節角度關鍵影格插值（角度走最短弧），Q 版比例（頭稍大、短手短腳，身高約 43px），頭為實心圓；遊戲畫面以 1.25 倍鏡頭拉近顯示（看得到的世界寬 384），HUD 不放大（見 [Shock 風格改版計畫](./shock-style-plan.md)）
- 測試：Vitest 測純邏輯（輸入判定、命條血池、傷害、掉落）；手感實玩調整
- 部署：Vercel；排行榜：Firebase
- 平台：桌機鍵盤

## 視角

純 2D 橫向（見 [ADR 0001](./adr/0001-pure-2d-side-view.md)），地面平坦，無平台。

## 操作

| 鍵 | 動作 |
|---|---|
| A D（或 ← →） | 移動；連按兩下並按住為**跑步**（跑步中起跳會帶著跑速） |
| W（或 ↑） | 跳；空中貼牆時再按一次為**蹬牆跳**（沒有獨立的跳躍鍵） |
| S（或 ↓） | 蹲下（閃避高攻擊／子彈） |
| J | 拳 / 持有物攻擊 |
| K | 踢 |
| L | 撿起 / 丟出持有物；空手且腳邊沒東西時**抓住**面前的雜兵 |
| Left Shift | **閃身步**：往按著的方向快速滑開約 45px（沒按方向或按身後 = 往後閃），面向不變，途中短暫無敵 |
| V | 背包：收槍、掏槍、使用醫療箱 |
| Esc / P | 暫停（同時打開設定面板：調音樂／音效音量、看所有操作說明、QUIT TO TITLE 回到主畫面——按兩次確認，不記錄成績） |

無防禦鍵。遊戲畫面不顯示按鍵提示；所有操作整理在標題的 **SETTINGS** 與暫停面板裡。音量（預設音樂 30%、音效 35%，每格 5%）存在瀏覽器。

### 手機版（觸控）

手機、平板（主要輸入是觸控）自動顯示觸控按鈕；網址加  可在電腦上強制顯示。只支援橫向，直拿時顯示「請將手機轉成橫向」。第一次觸碰會解鎖音效並嘗試全螢幕、鎖定橫向（iOS Safari 不支援時略過）。

- **左手：浮動搖桿**——左半邊任一處按下就是搖桿中心。左右 = A D、往下 = S、往上 = W（跳）；往上要推得明確（約 40° 以內），往前斜推不會誤跳
- **右手：按鈕**——拳（J）、踢（K）、抓（L）、閃（Shift）、包（V）、保命（一次送出 J+K+L）；左上角 ❚❚ 暫停
- 觸控按鈕產生的按鍵和鍵盤完全相同，所有指令（連按兩下跑步、S → W + J、前後前 + K、K K 踢下體、被抓時狂按）照樣能用
- 選單用搖桿上下選、拳確定；設定面板的提示會換成觸控說法，並列出按鈕與鍵盤的對照

### 招式（空手才能使用）

下表沿用舊的按鍵寫法：z = J、x = K、c = L、↑ = W、↓ = S、←→ = A D。

| 輸入 | 招式 |
|---|---|
| z 連按 | **三段拳**（第三段擊倒） |
| 空中 x | 空中踢：原地橫踢，不往前衝 |
| 空中 ←/→ + x | 飛踢：往該方向衝出去（擊倒） |
| 空中 ↓ + z | 下砸拳 |
| W + J／K 同時按 | 先起跳再出空中招式（攻擊比跳早按 3 幀內也算）；按著 A／D 時 K 變飛踢 |
| S → W + J | **挑空技**：把雜兵打上空中（Boss 不會浮空）；收招時按 W 可直接起跳追擊。S 到 W 約 0.27 秒內、W 到 J 約 0.2 秒內都算（按 J 時 S 沒放開也可以）；快速按 S 再按 W 時，跳會等 0.2 秒看有沒有接 J |
| 空中 z → z → x | **空中連段**：兩記空中拳接下砸踢，把敵人砸到地上反彈 |
| →→ + z／跑步中 z | 衝刺拳 |
| 跑步中 x | **跑步飛踢**：從地上低低跳起往前飛踢（擊倒，12 傷害），落地結束；和空中飛踢是不同的招 |
| x x 快速連按 | **踢下體**：往前上方踢下體（4 傷害），雜兵摀著下體彎腰、痛到原地小跳約 1.3 秒（期間不會出招、可以追打或抓住）；Boss 只會受傷不會彎腰。雜兵（THUG、BRUISER）也會踢特務的下體：起手看得到、蹲下躲不掉要跳開，被踢中摀著下體約 0.75 秒不能動 |
| ↓ + z | 蹲拳：蹲著出拳，腿不動，可連按 |
| ↓ + x | 掃腿：蹲著掃，全程不站起來（擊倒） |
| z + x + c 三鍵同時壓住（按下間隔約 50ms 內） | **保命招**：旋風腿打四周，消耗自身少量血量（擊倒）。c 的撿丟會延遲約 50ms，期間湊成三鍵就改放保命招；z + x 只會出踢 |

### 抓技

空手、腳邊沒東西時，走到雜兵面前按 c 就抓住（不用先打；對方出招到一半也抓得住，拳腳打中後的收招也能直接按 c 抓）；浮空、倒地、起身中的敵人和 Boss 抓不住。抓著什麼都不做約 2 秒，對方會掙脫；被其他敵人打中也會放開。

| 抓住後 | 招式 |
|---|---|
| z | **膝撞**：6、6，第三下 8 並撞倒 |
| x 或 前 + x | **往前摔**：12 傷害，摔飛的人會撞倒其他敵人、撞牆反彈 |
| 後 + x | **過肩摔**：舉過頭、下腰約 90° 摔到身後，16 傷害；途中無敵 |
| 前 → 後 → 前 + K（約 0.6 秒內輸入完） | **大風車**：先收頭蓄力再頭槌撞暈（5），對方往後倒、頭著地，抓起雙腳從腰部高度原地轉兩圈（頭從地上掃起來），掃倒兩側的敵人（10），最後依慣性甩到空中（14）；途中無敵 |

**被雜兵抓住**：BRUISER、HEAVY（空手時）會伸手抓特務（起手 12 幀看得到）。抓住後每隔約 0.5 秒膝撞一次（6），三下之後摔出去（10、擊倒）。被抓時狂按 J／K／L 或方向鍵，按滿 10 下就掙脫：對方踉蹌、特務短暫無敵。空中、倒地、閃身步途中不會被抓；被其他敵人打到也會鬆手。

## 持有物

同時只能持有一件；持有時無法使用招式。`c` 丟出有傷害。被**擊倒**時掉落持有物。

| 物件 | 類別 | 傷害 | 速度 | 距離 | 耐久／彈藥 | 特性 |
|---|---|---|---|---|---|---|
| 棍棒 | 近戰武器 | 中 | 中 | 中 | 10 | 擊倒 |
| 撬棍 | 近戰武器 | 中高 | 慢 | 中 | 15 | 耐用 |
| 小刀 | 近戰武器 | 低 | 快 | 短 | 12 | 丟出直線飛行、高傷害 |
| 武士刀 | 近戰武器 | 高 | 中 | 長 | 8 | 最強、易壞 |
| 手槍 | 槍械 | 中 | 中 | 遠 | 8 發 | 子彈命中一人即消失 |
| 霰彈槍（選配） | 槍械 | 高 | 慢 | 近中 | 4 發 | 扇形、擊倒 |
| 椅子 | 投擲物 | 中 | — | 拋物線 | 1 | 擊倒 |
| 櫃子 | 投擲物 | 高 | — | 短拋 | 1 | 穿透多人、持有時移動很慢 |

- 最後一發子彈打完，槍留在手上；下次扣扳機會「喀」一聲空扣、停頓一下，再把空槍往前丟出（打到人有傷害）；敵人槍手也一樣，丟完改用拳腳
- 沒子彈的槍一落地就消失（丟出去的、被擊倒時掉下來的都一樣），撿起來也沒用；有子彈的槍會留在地上
- **背包**：手以外的一格，可放一把槍或一個醫療箱；被擊倒時不會掉。v 鍵：手上拿槍且背包空 → 收進背包；背包有槍 → 掏出（手上是槍就互換，是其他武器就丟到地上）；背包有醫療箱 → 使用
- 彈藥包優先補手上的槍，其次補背包裡的槍
- 地上的槍滿彈；敵人掉落的槍彈藥隨機

## 打擊手感

頓幀 3–5 幀、硬直、擊退、擊倒（倒地無敵後起身）、重擊畫面震動、被擊飛者撞到其他敵人造成傷害。

打擊演出（慢動作以外都是純畫面，不影響判定）：

- **衝擊閃光**：畫在判定框與受擊框重疊處；輕擊是小星形，重擊（擊倒、挑空、重攻擊）加上擴散的衝擊環與往打擊方向噴的速度線；特務被打中是紅色
- **鏡頭推近**：撞牆、下砸踢命中、打斷 Boss 一條命條
- **清場慢動作**：打倒區段最後一波的最後一個敵人或魔王時，閃白＋鏡頭推近＋約 1 秒的 1/3 速度慢動作

**撞牆反彈**：被打飛的雜兵撞到牆（鎖定區段的畫面邊緣或樓層兩端）會彈回來、額外受 6 點傷害並變成浮空狀態，還能再追打兩下；每次被打飛只彈一次。

## 生命

- 單一血池以每 100% 為一條**命條**，顏色分段顯示
- 特務：3 條（300%），綠 → 黃 → 紅
- 醫療箱補 40%，可補回上一條，上限為滿血；背包空著時走過去會先收進背包（按 v 使用，滿血時不會浪費），背包滿了才直接補血
- 破完一層樓（走上樓梯）補 20%，同樣可補回上一條；血量獎勵以補血前的血量計算
- 小 Boss 2 條、Johnson 3 條；Boss 類每條對應一個**階段**

## 敵人

| 類型 | 顏色 | 行為 |
|---|---|---|
| 小混混 | 灰 | 基本拳腳，血少，量多 |
| 打手 | 藍 | 撿近戰武器，常帶棍棒／撬棍登場 |
| 刀手 | 綠 | 持刀、快速、衝刺突刺 |
| 槍手 | 紫 | 保持距離開槍，被近身會後退，掉彈藥 |
| 壯漢 | 橘 | 血厚、攻擊霸體、撿投擲物丟玩家 |

同類型內有些微色差。**攻擊名額** 2；每區段同時在場 4–5 人。

## 樓層

每層為 3–4 畫面寬的橫向捲軸，分數個**區段**（鎖鏡頭、清空後「GO →」），終點樓梯。血量與持有物帶到下一層。

| 樓層 | 主題（主色） | 結尾 |
|---|---|---|
| 1F | 大廳／停車場（白天、暖沙色） | 小 Boss（深紅）持撬棍，2 條命條 |
| 2F | 賭場／辦公室（夜晚、翡翠綠＋金柱、綠絨地板） | 小 Boss（深紅）雙持武士刀劍客，2 條命條；會**空翻斬**（蹲低預備 → 跳起空翻 → 落下時雙刀往下劈，落地後有空檔可反擊，空中可以打下來） |
| 3F | 頂樓／魔王辦公室（冷藍夜景、月亮） | 魔王 Johnson |

### 魔王 Johnson

金色、體型 1.3 倍、西裝＋帽子＋墨鏡，3 條命條：

1. 拳腳 + 衝撞
2. 拔槍掃射 + 呼叫雜兵
3. 抓狂加速 + 丟辦公桌

換階段時短暫無敵並有演出。

## 掉落

- 被擊倒的敵人必掉其持有物
- 額外機率：彈藥包 15%（僅槍手）、醫療箱 10%
- **箱子**打破必掉一項（醫療箱／武器／分數道具）

## 分數 (SCORE)

- 命中 +10；擊倒雜兵 +100–300（依類型）；小 Boss +2000；魔王 +10000
- **連擊**：連續命中且未被打中、間隔不超過 1.5 秒時累積；每 5 下分數倍率 +1（最高 x5），5／10／15／25 下顯示 GOOD／GREAT／EXCELLENT／INSANE
- 過層獎勵：剩餘血量與用時換算

## 流程

標題（START / LEADERBOARD / 更改暱稱）→「1F」字卡 → 樓層 → 樓梯過場 → … → Game Over 或 MISSION COMPLETE → 暱稱彈窗（首次）→ 上傳成績、顯示排行榜

- 不可接關，無時間限制
- 暫停 Esc / P

## 排行榜（最後實作）

- Firebase；排序：到達樓層（通關最高）→ 分數；顯示前 20
- 首次結束一局時詢問**暱稱**，可略過（以 ANONYMOUS 上傳）；暱稱存 localStorage，標題畫面可更改
- 接受被灌分風險，Security Rules 僅驗證數值範圍
