# 0001 — 採用純 2D 橫向視角，不做清版縱深

## 狀態
Accepted (2026-10-17)

## 背景
街機風格格鬥遊戲常見兩種視角：
- 有縱深的清版（belt-scroller，如 Final Fight、怒之鐵拳）：角色可在地面上下移動，Y 軸代表深度。
- 純 2D 橫向（如 Stick Fight）：只有 X 軸與跳躍高度。

## 決策
採用純 2D 橫向。角色只在 X 軸移動，Y 軸為跳躍／高度。

## 理由
- 碰撞、命中判定、AI 走位都只需處理一條軸，MVP 實作成本大幅降低。
- 火柴人以線條呈現，側面輪廓最清楚；縱深會帶來排序與遠近縮放問題。

## 後果
- 敵人只能從左右兩側包夾，敵人數量與節奏設計需配合（同時在場人數不宜過多）。
- 可以加入平台／高低差作為關卡變化。
- 日後若改為縱深清版，物理、AI、繪圖排序都要重寫——這是難以反轉的決定。
